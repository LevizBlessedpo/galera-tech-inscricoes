Formulário web de inscrição para o **Galera Tech**, programa de capacitação gratuita em tecnologia, com aulas presenciais à tarde, exclusivo para estudantes do Ensino Médio de escolas públicas.

Projeto de conclusão de curso, desenvolvido para a **APETI**.

> **Status:** Front-end concluído. Integração com PHP e MySQL em desenvolvimento.

---

## 📌 Sobre o projeto

O objetivo é oferecer um sistema simples e confiável para cadastrar os candidatos ao programa, substituindo o processo manual de inscrição. O formulário coleta, valida e (na versão final) grava os dados dos estudantes em um banco de dados.

---

## ⚙️ Funcionalidades

- Formulário dividido em 5 seções: dados pessoais, residência, informações escolares, dados do responsável e declarações.
- Validação de campos no navegador (CPF, e-mail, telefone com DDD, CEP, campos obrigatórios).
- Dados do responsável obrigatórios apenas para menores de 18 anos.
- Regras de transporte exibidas conforme a cidade de residência.
- Aviso de Privacidade e Tratamento de Dados (conforme a LGPD) em página própria.
- Layout responsivo, pensado para uso no celular.
- Interface com identidade visual própria sobre o Bootstrap.

## 🧪 Ambiente de testes

Esta versão é uma demonstração. Use **somente dados fictícios** ao testar no seu ambiente local (Laragon). O Aviso de Privacidade é uma minuta e deve ser revisado pela organização antes do uso com dados reais.
